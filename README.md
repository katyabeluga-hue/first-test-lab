# first-test-lab

Небольшая учебная C++ программа: просит пользователя ввести целое неотрицательное число, проверяет ввод и выводит результат.

## Что делает программа

1. Запрашивает ввод: `Введите целое неотрицательное число:`.
2. Проверяет, что введена непустая строка, состоящая только из цифр 0–9.
   Отрицательные числа, дробные, пробелы, буквы и любые другие символы считаются ошибкой.
3. При ошибке выводит сообщение и просит ввести число заново, пока ввод не будет корректным.
4. При корректном вводе выводит `Вы ввели: <значение>`.

Особенности:
- Число хранится как строка, поэтому очень длинные числа не переполняют `int`.
- Ведущие нули сохраняются (`007` выведется как `007`).
- При завершении ввода (Ctrl+D) программа выходит с кодом 1.

## Структура проекта

```
src/test.cpp   исходный код программы
```

## Сборка и запуск

Требуется компилятор с поддержкой C++17 (g++ или clang++).

```sh
g++ -std=c++17 src/test.cpp -o test
./test
```

Пример:

```
Введите целое неотрицательное число: abc
Ошибка: нужно ввести только цифры (без пробелов, знаков и букв). Попробуйте ещё раз.
Введите целое неотрицательное число: 42
Вы ввели: 42
```
